## 📌 Dataset Overview

This dataset contains information about sleep health and lifestyle factors for 374 individuals.

The data includes:

- Age
- Sleep Duration
- Quality of Sleep
- Stress Level
- Physical Activity Level
- Heart Rate
- Daily Steps
- BMI Category
- Sleep Disorder
