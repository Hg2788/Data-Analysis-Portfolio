# Brazilian-Ecommerce-Repeat-Customer-Analysis

## Project Overview

This project analyzes repeat customer behavior using the Brazilian E-commerce Olist Dataset.

The goal is to identify the characteristics of repeat customers, analyze purchasing patterns and customer value through SQL, and visualize key insights with an interactive Tableau dashboard.

## Key Findings

### Customer Value Analysis

* **Average Order Value (AOV)**
  * Repeat: **$108.57** | One-time: **$120.84**
  * One-time customers spent more per order.

* **Customer Lifetime Value (CLV)**
  * Repeat: **$249.52** | One-time: **$120.84**
  * Repeat customers generated over **2× higher lifetime value**.

### Purchasing Behavior Analysis

* **Average Items per Order**
  * Repeat: **1.21** | One-time: **1.14**
  * Repeat customers purchased slightly more items per order.

### Customer Experience Analysis

* **Review Score**
  * Repeat: **4.15** | One-time: **4.08**

* **Delivery Delay Rate**
  * Repeat: **7.03%** | One-time: **8.19%**
  * Repeat customers experienced fewer delayed deliveries.

### Product & Regional Analysis

* **Top Product Categories**
  * Bed Bath Table, Furniture Decor, Sports Leisure

* **Highest Repeat Purchase Rate**
  * **Rio de Janeiro (RJ)** recorded the highest repeat purchase rate (**3.40%**) among the analyzed states.
